# Sample research intake

Create a **Research library** focus area and add papers or citation files to it. Research resources are grouped by topic and are never blocked by coursework prerequisites.

Useful filename patterns for local metadata inference:

```text
Ada Lovelace - Analytical Engine Notes 1843.pdf
Attention_Is_All_You_Need_2017_doi_10.48550/arXiv.1706.03762.pdf
```

The first pattern infers an author and title. The second infers a title, year, and DOI. For complete metadata later, add a `.bib`, `.ris`, `.csljson`, or API-enrichment layer.
